# Travo

Agentic legal-process platform for Southeast Asian law firms — starting with
contract & agreement review for Vietnam, Singapore, Indonesia and Malaysia.

- **Grounded:** deep legal RAG with per-claim citation validation.
- **Neutral:** model-agnostic router across frontier and open-weight models, so
  firms avoid vendor lock-in and provider conflicts.
- **Private:** tenant and matter isolation, ethical walls, regional data residency.
- **Learns from the firm:** in-house expert corrections feed firm-private
  improvements.
